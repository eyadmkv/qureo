# Code of Conduct

## Our commitment

We want participation in this project to be respectful, constructive and safe for everyone, regardless of experience, identity, background or point of view.

## Expected behavior

- Be respectful and considerate.
- Give actionable feedback and explain technical disagreements without personal attacks.
- Accept responsibility for mistakes and correct them when possible.
- Respect other contributors' time, privacy and boundaries.
- Keep discussions focused on the project.

## Unacceptable behavior

- Harassment, insults, threats or discriminatory language.
- Sexualized language or unwelcome advances.
- Publishing another person's private information without permission.
- Deliberate disruption, trolling or sustained bad-faith behavior.
- Any other conduct that would be inappropriate in a professional technical community.

## Enforcement

Project maintainers are responsible for clarifying and enforcing this policy. To report behavior that violates this Code of Conduct, contact the maintainers privately through the GitHub repository. Reports will be reviewed and handled as confidentially as practical.

Maintainers may remove or edit contributions, close discussions, or restrict participation when necessary. Decisions will be based on the impact and context of the behavior.

## Scope

This policy applies in project spaces, including issues, pull requests, code reviews and other project-related communication.

This Code of Conduct is adapted from the Contributor Covenant, version 2.1: https://www.contributor-covenant.org/version/2/1/code_of_conduct.html
